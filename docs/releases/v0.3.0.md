## v0.3.0

### Features / 新功能
- Tunnel: saved port-mapping list — add, start, stop, delete; persist in localStorage; sessions don't auto-restart（穿透：端口映射可保存，增删启停，写入 localStorage，会话不自动重开）
- QR for owned keys only; scan a peer address from the camera, an image, or the system clipboard (image or `tc…` text)（仅对自己的密钥显示二维码；输入对端地址时可相机扫描、选图，或从系统剪贴板粘贴图片 / `tc…` 文本）
- Lobby loading state when creating a room（大厅创建房间时显示加载状态）

### Fixes / 修复
- QR share/scan dialogs portal to `document.body`, so glass `backdrop-filter` no longer clips them（二维码分享/扫描对话框挂到 `document.body`，不再被毛玻璃 `backdrop-filter` 裁切）
- Tunnel mapping keys stay in the card as a Markdown-style code block with a corner copy button（穿透映射密钥不再溢出卡片，改为 Markdown 代码块并带角落复制）
- Restart-room hint truncates long keys; crowded sidebar room list scrolls with no visible scrollbar（重启房间提示截断长密钥；侧栏房间挤满时可滚动且不显示滚动条）

### Polish / 优化
- PolyForm Noncommercial 1.0.0 license; Release and platforms badges on the README（PolyForm Noncommercial 1.0.0 许可；README 增加 Release 与平台徽章）
- README demo GIFs in dark mode, English and Chinese in one row（README 演示 GIF：深色模式，中英同一行）

Binaries are unsigned. Gatekeeper / SmartScreen warnings are expected.
未签名构建；macOS Gatekeeper / Windows SmartScreen 警告属正常。
