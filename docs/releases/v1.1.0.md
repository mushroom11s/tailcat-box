## v1.1.0

Minor release after 1.0.0（1.0.0 之后的小版本）。

### Highlights / 亮点
- Desktop notifications when a peer connects and for 喵传（桌面通知：对端连接，以及喵传相关提醒）
- First-run guide for your address, rooms, and Mew Share（首次使用引导：地址、房间与喵传）
- 喵传: retry a failed download, and warn before a share expires or you go offline（喵传：失败的下载可重试；分享即将过期或离线前提醒）
- Settings names the update check 「检查更新」（设置：更新检查的文案是「检查更新」）
- Chat: search messages in the current room, and pin rooms（聊天：搜索当前房间的消息，并可置顶房间）
- 喵传 files of 300 MiB or less still copy into app temp; larger files are not copied and are served from the original path, with a clear error if that file is moved or deleted while sharing（喵传：不超过 300 MiB 仍复制到应用临时目录；更大的文件不复制，从原路径提供；分享期间文件被移动或删除时给出明确错误）
- Room and new-room peer fields accept a pasted address or QR image, with hints; QR views have a compact 「复制」 chip that copies the QR as a PNG, while copying an address or code is unchanged（房间与新建房间的对端栏可粘贴地址或二维码图片，并有提示；二维码界面有紧凑的「复制」，把二维码复制成 PNG，地址与口令的复制不变）

Binaries are unsigned. Gatekeeper / SmartScreen warnings are expected.
未签名构建；macOS Gatekeeper / Windows SmartScreen 警告属正常。
