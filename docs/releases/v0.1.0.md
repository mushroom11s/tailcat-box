# Tailcat Box v0.1.0

First public GitHub Release of **Tailcat Box** (猫砂盆).

---

## English

**Tailcat Box** is a Wails (Go + React) desktop GUI for [Tailscale Tailcat](https://github.com/tailscale/tailcat) on **macOS** and **Windows**. The engine is embedded `github.com/tailscale/tailcat` **v0.7.0**. The UI never imports Tailcat types; only `internal/adapter` does.

Product focus is **chat first**, with Tunnel and Settings beside it. Older toolbox pages are not the primary nav.

### What shipped

| Area | In this build |
| --- | --- |
| **Chat** | Native chat UI with a Tailcatchat-compatible protocol (ports 100–103): text, resumable files, burn-after-read, voice notes, WebRTC voice / video / screen share. Peer discovery via `tc` address exchange. Local multi-select delete (drag rectangle, icon top bar, confirm). Composer: Send on the far right; burn-after-read toggle to its left. |
| **Tunnel** | Port serve and local forward. Local forward can open the forwarded URL in a browser (editable port). |
| **Settings** | Theme and language; Client Info (uptime, app version, Tailcat version, last update check) and System Info; Keys / DERP and Diagnostics as subsections. |
| **UI** | Stronger Liquid Glass shell (frosted window, purple/blue ambience, chat as visual focus) across Chat / Tunnel / Settings. English + zh-CN. Pixel-art cat logo for app / tray / sidebar. |
| **Foundation** | Ephemeral pipe serve/dial, named keys, address parse/resolve, file inbox / SFTP / remote list, SSH serve/client, SOCKS5, exit-node, exec, tray Open + Quit (closing the window hides the app). |

### Fake vs real adapter

- **Real (default)** in `wails dev` / release binaries: public DERP relays, real WireGuard paths.
- **Fake** (`TAILCAT_ADAPTER=fake`): offline UI and tests, deterministic `tc:fake-…` addresses, no network.
- Vite without Wails uses an in-browser fake and shows an “In-browser fake adapter” chip.

### Platforms

GitHub Actions builds these artifacts (**unsigned**):

- `tailcat-box-macos-arm64-v0.1.0.zip` — Apple Silicon (`.app`)
- `tailcat-box-macos-amd64-v0.1.0.zip` — Intel Mac (`.app`)
- `tailcat-box-windows-amd64-v0.1.0.zip` — Windows x64 (`.exe`)
- `tailcat-box-windows-arm64-v0.1.0.zip` — Windows ARM64 (`.exe`)

Linux is not a v1 product target.

### Known gaps

- **Unsigned binaries.** No Apple notarization, no paid Apple Developer codesign, no Windows Authenticode. Gatekeeper and SmartScreen warnings are expected.
- **No auto-update.** Install the zip from this Release.
- **Public DERP** is best-effort and rate-limited; upstream Tailcat has no stability guarantee.
- Real two-device Tailcatchat interop and live A/V on a production network are still best validated on your own machines.
- Android, PTY, allowlists, and DNS publishing remain out of scope.

### Install (unsigned)

**macOS:** unzip, drag `tailcat-box.app` to Applications (or run in place). If Gatekeeper blocks it: System Settings → Privacy & Security → Open Anyway, or right-click → Open.

**Windows:** unzip and run `tailcat-box.exe`. If SmartScreen appears, choose More info → Run anyway. WebView2 is required (usually already installed on current Windows).

## 中文

**猫砂盆**（Tailcat Box）的首个公开构建：用 Wails（Go + React）在 **macOS** 和 **Windows** 上操作 [Tailscale Tailcat](https://github.com/tailscale/tailcat)。引擎是嵌入的 `github.com/tailscale/tailcat` **v0.7.0**。界面不直接依赖 Tailcat 类型，只有 `internal/adapter` 会导入它。

产品以 **聊天为核心**，侧栏为聊天 → 穿透 → 底部设置。

### 本版本包含

| 模块 | 能力 |
| --- | --- |
| **聊天** | 原生桌面聊天，兼容 Tailcatchat 协议（端口 100–103）：文本、可续传文件、阅后即焚、语音消息、WebRTC 语音 / 视频 / 屏幕共享。用 `tc` 地址互换加好友。本地多选删除（框选、图标顶栏、确认）。发送按钮在输入栏最右侧，左侧为阅后即焚开关。 |
| **穿透** | 端口服务与本地转发；本地转发可带「在浏览器打开」（端口可改）。 |
| **设置** | 主题与语言；客户端信息（运行时长、应用版本、Tailcat 版本、上次检查更新）与系统信息；密钥 / DERP、诊断为子页。 |
| **界面** | 加深版 Liquid Glass（毛玻璃窗口、紫蓝氛围、聊天为视觉焦点），英 / 中文，像素猫 logo。 |
| **基础能力** | 临时 pipe 服务与拨号、命名密钥、地址解析、文件收件箱 / SFTP / 远端列表、SSH 服务与客户端、SOCKS5、出口节点、exec、托盘打开 / 退出（关窗口隐藏，会话可继续）。 |

### 假适配器 vs 真适配器

- **真适配器（默认）**：公网 DERP 与真实 WireGuard。
- **假适配器**（`TAILCAT_ADAPTER=fake`）：离线演示与测试，地址为确定的 `tc:fake-…`。
- 无 Wails 时纯 Vite 使用浏览器内假适配器。

### 平台

GitHub Actions 产出以下**未签名**制品：

- `tailcat-box-macos-arm64-v0.1.0.zip` — Apple Silicon
- `tailcat-box-macos-amd64-v0.1.0.zip` — Intel Mac
- `tailcat-box-windows-amd64-v0.1.0.zip` — Windows x64
- `tailcat-box-windows-arm64-v0.1.0.zip` — Windows ARM64

Linux 不是 v1 产品目标。

### 已知缺口

- **未签名。** 没有 Apple 公证 / 付费开发者签名 / Windows Authenticode。Gatekeeper 与 SmartScreen 警告属预期。
- **没有自动更新。** 请从此 Release 下载 zip。
- **公网 DERP** 尽力而为且有速率限制；上游 Tailcat 不做稳定性承诺。
- 真机双端 Tailcatchat 互通与音视频仍建议在自己的设备上验证。
- Android、PTY、allowlist、DNS 发布仍不在范围内。

### 安装（未签名）

**macOS：** 解压后把 `tailcat-box.app` 拖到「应用程序」（或直接运行）。若被拦截：系统设置 → 隐私与安全性 → 仍要打开，或右键 → 打开。

**Windows：** 解压后运行 `tailcat-box.exe`。若出现 SmartScreen：更多信息 → 仍要运行。需要 WebView2（当前 Windows 通常已安装）。
