# Tailcat Box v0.1.0 (draft)

Draft GitHub Release notes for the first public tag. Edit this file on `main` before pushing `v0.1.0`.

---

## English

First desktop build of **Tailcat Box** (猫砂盆): a Wails (Go + React) GUI for [Tailscale Tailcat](https://github.com/tailscale/tailcat) on **macOS** and **Windows**. The engine is the embedded `github.com/tailscale/tailcat` **v0.7.0** library. The UI never imports Tailcat types; only `internal/adapter` does.

### Plans 1–4

| Plan | What you can do in this build |
| --- | --- |
| **1 — Foundation** | Start an ephemeral pipe serve, copy the Tailcat address, dial that address, transfer a short text payload. |
| **2 — Ports, keys, ping** | TCP port serve / local forward / browse a served HTTP port; create, list, delete named keys; parse and resolve addresses; Diagnostics ping (including until-direct). |
| **3 — Files** | Recv into an inbox, send/copy to a peer, serve a directory over SFTP, list remote paths. Session lists stay stable across poll refreshes. |
| **4 — SSH, SOCKS, exit-node, exec, DERP, tray** | SSH serve (keyed or no-auth with a typed `CONFIRM` gate), SSH client command, local SOCKS5 proxy, exit-node serve, per-connection exec, persist DERP region / map URL on Keys, tray/menu Open + Quit. Closing the window hides it so sessions can keep running. |

### Fake vs real adapter

- **Real (default)** in `wails dev` / release binaries: public DERP relays, real WireGuard paths. Pipe dial uses TCP port **1**; files/SSH use port **22**.
- **Fake** (`TAILCAT_ADAPTER=fake`): offline UI and tests, deterministic `tc:fake-…` addresses, no network.
- Vite without Wails uses an in-browser fake and shows an “In-browser fake adapter” chip.

### Platforms

GitHub Actions builds these artifacts (unsigned):

- `tailcat-box-macos-arm64-v0.1.0.zip` — `.app` from `macos-latest` (Apple Silicon)
- `tailcat-box-macos-amd64-v0.1.0.zip` — `.app` from `macos-15-intel` (Intel)
- `tailcat-box-windows-amd64-v0.1.0.zip` — `.exe` from `windows-latest` (x64)
- `tailcat-box-windows-arm64-v0.1.0.zip` — `.exe` from `windows-11-arm` (ARM64)

Linux is not a v1 product target.

### Settings

A **Settings** nav item exists on `main` as a placeholder (theme/language will move there). The full Settings page (client/system info, launch-at-login, `internal/appinfo` version stamp) is **not shipped** in this tag; it is still an open PR (`UI: Settings page`). Release builds still pass `-ldflags` for `internal/appinfo.Version` so that symbol is ready if Settings merges later.

### Known gaps

- **Unsigned binaries.** No Apple notarization, no paid Apple Developer codesign, no Windows Authenticode. macOS Gatekeeper and Windows SmartScreen will warn. That is expected for v1.
- **No auto-update.** Install the zip from this Release.
- **Public DERP** is best-effort and rate-limited; upstream Tailcat has no stability guarantee.
- **Android**, PTY, allowlists, and DNS publishing remain out of scope.

### Install (unsigned)

**macOS:** unzip, drag `tailcat-box.app` to Applications (or run in place). If Gatekeeper blocks it: System Settings → Privacy & Security → Open Anyway, or right-click → Open.

**Windows:** unzip and run `tailcat-box.exe`. If SmartScreen appears, choose More info → Run anyway. WebView2 is required (usually already installed on current Windows).

## 中文

**猫砂盆**（Tailcat Box）的首个公开构建：用 Wails（Go + React）在 **macOS** 和 **Windows** 上操作 [Tailscale Tailcat](https://github.com/tailscale/tailcat)。引擎是嵌入的 `github.com/tailscale/tailcat` **v0.7.0**。界面不直接依赖 Tailcat 类型，只有 `internal/adapter` 会导入它。

### 计划 1–4

| 计划 | 本版本可用能力 |
| --- | --- |
| **1 — 基础** | 启动临时 pipe 服务、复制 Tailcat 地址、拨号并传输短文本。 |
| **2 — 端口、密钥、Ping** | TCP 端口服务 / 本地转发 / 浏览已服务的 HTTP 端口；创建/列出/删除命名密钥；解析与解析地址；诊断页 Ping（含 until-direct）。 |
| **3 — 文件** | 收件箱 recv、向对端 send/copy、用 SFTP 共享目录、列出远端路径。会话列表在轮询刷新时保持稳定。 |
| **4 — SSH、SOCKS、出口节点、exec、DERP、托盘** | SSH 服务（密钥或需输入 `CONFIRM` 的无认证）、SSH 客户端命令、本地 SOCKS5、出口节点、按连接 exec、在“密钥与地址”保存 DERP 区域/地图 URL、托盘/菜单 Open + Quit。关闭窗口会隐藏而不退出，会话可继续跑。 |

### 假适配器 vs 真适配器

- **真适配器（默认）**：走公网 DERP 和真实 WireGuard。Pipe 拨号用 TCP **1** 端口；文件/SSH 用 **22**。
- **假适配器**（`TAILCAT_ADAPTER=fake`）：离线演示和测试，地址为确定的 `tc:fake-…`，不走网络。
- 没有 Wails 时，纯 Vite 使用浏览器内假适配器，并显示“浏览器内假适配器”标记。

### 平台

GitHub Actions 产出以下**未签名**制品：

- `tailcat-box-macos-arm64-v0.1.0.zip` — 来自 `macos-latest` 的 `.app`（Apple Silicon）
- `tailcat-box-macos-amd64-v0.1.0.zip` — 来自 `macos-15-intel` 的 `.app`（Intel）
- `tailcat-box-windows-amd64-v0.1.0.zip` — 来自 `windows-latest` 的 `.exe`（x64）
- `tailcat-box-windows-arm64-v0.1.0.zip` — 来自 `windows-11-arm` 的 `.exe`（ARM64）

Linux 不是 v1 产品目标。

### 设置页

`main` 上已有 **设置** 导航占位（主题/语言之后会移到这里）。完整设置页（客户端/系统信息、开机启动、`internal/appinfo` 版本号）**尚未合入**，仍在开放的 Settings PR 中。Release 构建仍会传入 `internal/appinfo.Version` 的 `-ldflags`，以便该 PR 合并后能显示版本。

### 已知缺口

- **未签名。** 没有 Apple 公证、没有付费 Apple 开发者签名、没有 Windows Authenticode。macOS Gatekeeper 和 Windows SmartScreen 会警告，这是 v1 的预期行为。
- **没有自动更新。** 请从此 Release 下载 zip。
- **公网 DERP** 是尽力而为且有速率限制；上游 Tailcat 不做稳定性承诺。
- **Android**、PTY、allowlist、DNS 发布仍不在范围内。

### 安装（未签名）

**macOS：** 解压后把 `tailcat-box.app` 拖到“应用程序”（或直接运行）。若被拦截：系统设置 → 隐私与安全性 → 仍要打开，或右键 → 打开。

**Windows：** 解压后运行 `tailcat-box.exe`。若出现 SmartScreen：更多信息 → 仍要运行。需要 WebView2（当前 Windows 通常已安装）。
