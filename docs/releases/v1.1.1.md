## v1.1.1

Patch after 1.1.0（1.1.0 之后的补丁）。Windows 发布重新带上便携 zip，安装包文件名带上 `installer`。

### Highlights / 亮点
- Windows Release again includes a portable zip. Unzip it and double-click `tailcat-box.exe`（Windows 再次提供便携 zip：解压后双击 `tailcat-box.exe`）
- The Windows installer filename now includes `installer`, so it is not confused with the portable build（Windows 安装包文件名包含 `installer`，不会和便携版搞混）
- Copying a QR no longer shows a success toast; it still copies the PNG（复制二维码不再弹出成功提示；仍会复制 PNG）

Binaries are unsigned. Gatekeeper / SmartScreen warnings are expected.
未签名构建；macOS Gatekeeper / Windows SmartScreen 警告属正常。
